# Support / 支持

Fast.NET is community-maintained open-source software. Use the [Gitee issue tracker](https://gitee.com/FastDotnet/Fast.NET/issues) for reproducible defects and focused feature requests.

Fast.NET 是社区维护的开源软件。可复现缺陷和明确的功能建议请提交到 [Gitee Issues](https://gitee.com/FastDotnet/Fast.NET/issues)。

Before opening an issue, search existing issues and provide:

- package name and exact version;
- .NET runtime, operating system, and hosting model;
- minimal reproduction or focused code sample;
- expected and actual behavior;
- complete relevant exception and logs with secrets removed.

提交 Issue 前请先搜索已有问题，并提供：包名与精确版本、.NET 运行时、操作系统、宿主模型、最小复现、预期与实际行为，以及移除敏感信息后的完整相关异常和日志。

Security reports follow [`SECURITY.md`](SECURITY.md). General .NET, Redis, Consul, SqlSugar, database, or deployment questions that do not depend on Fast.NET behavior should use the corresponding upstream community.
